# 当前比赛规则：v0.4 轮换占点

代码权威来源：`scripts/trial_rules.py`；参数继承链为 `trial_v3.json → trial_adaptive.json → trial_rotating.json`，由 `adaptive_motion.load_config` 合并。名称中的 v3 是历史文件名，不代表启动了旧版永久失效规则。

## 1. 任务与观测

A 为 Go2-W 轮足四足，B 为 G1 人形。A 的优化目标是累计占点分；B 主要通过巡逻、搜索、追踪和有效射击施压。B 不通过占点计分，也不会因进入点内自动争夺/冻结 A 的计分。

基线演示中 A 可获得对方状态，B 仍为有限可见性策略。非全知 LLM 比赛中，A 仅知道地图、规则、对手初始位置，然后通过 RGB 和视觉记忆决策。二者信息条件不同，不应把基线得分作为公平的同观测模型对照。

## 2. 数值和坐标

| 参数 | A | B / 公共 |
| --- | --- | --- |
| 初始位置 xy（m） | (-5, -2.8) | (5, 2.8) |
| 初始生命 | 3 | 3 |
| 最大平移速度（m/s） | 1.1 | 0.65 |
| 最大平移加速度（m/s²） | 2.0 | 1.2 |
| 最大机身角速度（rad/s） | 2.5 | 3.0 |
| 代表点高度（m） | 0.40 | 1.05 |
| 瞄准增长时间常数 τ（s） | 1.0 | 0.5 |
| 命中强度上限 λmax（s⁻¹） | 1.5 | 1.5 |
| 有效射击距离 | ≤8 m | 同左 |
| 射击视锥 | 正前 ±30°，合计 60° | 同左 |
| 命中后自身冷却 | 2 s | 同左 |

世界 Z 向上；xy 单位米，yaw 单位弧度，0 朝 +X，π/2 朝 +Y。裁判步长 `dt=0.02 s`，最多 `40 s`。路径网格 `0.2 m`、障碍中心安全距离 `0.42 m`、存活机器人最小中心间距 `1.05 m`。这些是运动学几何保护，不是完整身体碰撞模型。

## 3. 有效瞄准和随机命中

必须同时满足：双方存活、攻击已使能、射手不在冷却、距离/机身正前视锥合法、代表点三维连线不被掩体阻挡。相机云台转向不改变机身射击方向。

连续有效瞄准年龄为 a 秒：

```text
λ(a) = λmax × (1 − exp(−a / τ))
H(a) = λmax × [a − τ × (1 − exp(−a / τ))]
P(在 [a, a+Δt] 命中 | 此前未命中) = 1 − exp(−(H(a+Δt) − H(a)))
```

`λ` 是每秒条件命中强度，不是直接取值 0–1 的“这一帧命中概率”。实现对每段连续瞄准抽取一次指数阈值，累计危险量 H 达阈值即命中；避免因渲染 FPS 变化而改变概率法则。瞄准中断清零，下次有效时重新抽取。人形 τ 更小，因此相同连续瞄准时间下更快逼近强度上限。

命中扣目标 1 HP，命中本身不加分。**只有成功命中的射手**开始 2 秒冷却；冷却期间不累计瞄准。双方在同一裁判步上的候选命中使用伤害前状态生成，允许同时命中。随机流按角色分开，固定 seed 可复现裁判随机性，但 LLM 随机输出不因此变成确定性。

## 4. 占点生命周期

初始只有 P1 有效。P1 中心 (-4, -1.5)，P2 中心 (-1, 3.25)，半径均 0.55 m。当前点与“目标代数 generation”共同标识一次占点机会。

```text
生成 P1 → 等待首次进入（不倒计时）
         → 首次进入：启动 5 s 期限
         → 连续驻留超过 1 s：每秒 1 分
         → 到期，或 A 在该圈内受击：本代失效
         → 立即生成 P2 → 同样流程 → 生成新一代 P1 → ...
```

- 进入/离开由 A 身体 xy 质点是否处于圆内判定。
- 离圈重置连续驻留；重新进入仍沿用同一代原期限，不再给 5 秒。
- 受击发生在有效圈外：扣血但不使当前点失效。
- 受击发生在有效圈内：即使尚未驻留满 1 秒，也使当前代失效；累计已得分不撤回。
- B 站在点内不额外冻结 A；B 的主要阻止手段是攻击。
- 同代点失效后不能继续计分；以后轮换回来的是新 generation，可再次得分。
- 无受击且一直在圈内，理论上一次触发窗口最多约 4 分（5 秒期限减 1 秒驻留），实际边界按 dt 量化。

## 5. 终局与事件结算

当 A 的 HP 清零，立即结束；或到 40 秒结束。双方不复活。B 被击败后 A 仍能占点直到终局。当前循环刷新模式中通常不存在“所有点永久失效”的终局；该条件仅适用于旧 v0.3 非轮换配置。

裁判先结算上一时间区间已经合法产生的占点分，再处理当前时间边界的失效与命中；不会倒扣之前已经获得的分数。达到时限时先结束，不继续生成该边界的新射击。所有圆边界、遮挡和事件时间按 0.02 秒采样，有步长量化误差；不是连续刚体碰撞求解。

## 6. 固定坍塌

在第 20 秒将比赛场地的 `High3` 替换为已知倒伏障碍，绕配置轴旋转 90°。运行时几何是一次确定性切换，不求解真实破坏或碎块刚体。回放可用约 2 秒视觉动画展示倒下过程，不能据此反推裁判也经历同样缓慢坍塌。

不造成砸伤，不暂停无关的连续瞄准。切换后重新做 LOS 和路线规划；原本仍合法的瞄准继续计时。规划预留扫掠范围，并拒绝不安全重叠；变更坍塌参数后必须同步更新预留区和测试。

大地图 DOCK 07 有自己的固定墙体/枢轴/倒伏几何，仅是场景验证，并未把大地图接入上述比赛裁判。

## 7. 人形与技能决策不是裁判规则

人形理想几何传感器为正前总计 120°、范围 8 m；射击仍需正前 60°。失去目标后最多保留 4 秒最后观测，按最后观测位置搜索/扫视，之后继续巡逻；搜索/巡逻扫描速率 2.4 rad/s，受身体角速度限制。它不是始终知道 A 真值的追踪器，也不是相机 RGB 检测网络。

路径风险权重、低血量规避、倒退、搜索顺序等属于策略层。改变它们会改变实验条件，但不应偷偷修改裁判公式。参数修改时保留继承源、新配置、seed 和源码版本，见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
