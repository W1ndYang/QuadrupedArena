## 2. 概率模型及与占点门槛的关系

连续有效瞄准时间记为 a：

```text
λ_i(a) = 1.5 × (1 − exp(−a / τ_i))
H_i(a) = 1.5 × [a − τ_i × (1 − exp(−a / τ_i))]
p_i(a, Δt) = 1 − exp(−[H_i(a+Δt) − H_i(a)])
```

实现为每次连续瞄准开始抽一个 Exp(1) 阈值 E，H(a) 达到 E 即命中；不是每帧用累计概率反复抽签。事件日志保存实际阈值、瞄准时长和 H，便于复算。命中时刻量化至 0.02 s。离圈/遮挡/角度变化的检测也有该量级的采样误差。

从一次瞄准开始到指定时长，至少发生一次首次命中的累计概率如下；不是“下一帧命中概率”：

| 连续有效瞄准时长 | 轮足 A | 人形 B |
| --- | --- | --- |
| 0.5 s | 14.77% | 24.11% |
| 1.0 s | 42.41% | 57.32% |
| 2.0 s | 81.79% | 89.60% |

因此，假设人形在轮足进圈时恰好从零开始有效瞄准，轮足在 1 秒门槛前被命中的概率约 57.3%。如果人形更早瞄准，风险更高；如果被墙挡住或角度不足，不能直接套用此数值。这组参数是可解释的起点，不意味着已经阻止了所有“冲点”策略。

遮挡/超角度/超射程使自身瞄准清零；命中方清零并冷却。受击方如仍存活且瞄准仍有效，保留自己的瞄准进度。场地变化只重新检查几何，不全局清空仍有效的瞄准。

边界结算口径：先结算上一裁判步已经合法积累的驻留和得分，再处理当前采样点的命中和失效；不回扣合法旧分。达到时间上限先结算并结束，不额外处理该时刻的新射击。

## 3. 坍塌的首轮实现边界

指定 `High3`，初始中心 (-1,2.4,0.9)，尺寸 2×0.4×1.8 m。以 (-1,2.2,0) 为轴上点，绕 +X 旋转 +90°；最终中心 (-1,1.3,0.2)，尺寸 2×1.8×0.4 m，成为向场内倾倒的完整低矮墙板。

- 裁判在 t=20 s 切换固定几何；显示、USD 碰撞形状、遮挡和规划使用对应终态。
- GIF 插入 2 秒墙体旋转慢镜头，属于瞬时事件的展示，不增加比赛时间；不是游戏全局暂停，也没有给受击方保护期。
- 初版不做碎裂、自由刚体散落、砸伤、随机终态，也不开放跨越低矮残骸；“坍塌”目前是受控墙板倾倒。
- 基线规划器从开局即预留已知倾倒扫掠区，双方避开；扫掠区只限制规划，不成为隐形射线遮挡。切换时再次检查存活机器人中心的安全余量，不安全则报告失败，不瞬移机器人。
- 本轮为保守控制器，倾倒预留区在事件后仍保留；所以不能用本轮证明规划器已利用所有新开放通道。后续可改为终态精确通行区。
- 导出 `arena_before.usda`、`arena_after.usda`（干净地面/墙体）及 `demo_final_pose.usda`（含演员与演示辅助图形）。前后墙体世界包围盒已与裁判尺寸自动核对，并检查 CollisionAPI；这不是接触动力学验证。

开局 `High3` 相比旧样场向场内移动 0.3 m，目标位置重新布置，避免圈与墙相交。不是把旧场景仅换一张贴图。

## 4. 本轮控制器与信息边界

双方使用地图真值和当前对方位置，不读取随机阈值、未来命中时刻或对方未来路线。无噪声/时延。画面 HUD 可展示裁判瞄准进度，但不意味着未来策略必须获得这些内部状态。

轮足基线：选择最近的未失效目标 → A* 绕墙到目标 → 驻留计分 → 目标失效后重新选择。运动中按路径转向，停止时朝向对手。没有训练、风险代价或主动探头/撤回策略。

人形决策树：

```text
已淘汰 → 停止并从演示场景移除
自身冷却 → 暂停追击、继续朝向轮足（只是一种对手策略，非规则禁止移动）
距离合适且无遮挡 → 转向轮足、持续瞄准
否则 → 搜索有射击视线的位置，用 A* 接近，每 2 秒/路径结束重规划
```

自动射击由独立裁判执行，决策树不能自行扣血或加分。新规则不沿用旧演示的固定 0.8 s 锁定、双边暂停或目标定时切换。

双方设 0.85 m 中心间距的保守避碰停止线；它不是完整动态避障。此次出现了轮足在 P2 前被人形挡住、停止后继续交火的现象，是基线缺陷，不是想要训练出的策略。机器人 URDF 外观、关节/轮子动画均为运动学；未运行腿部平衡、接触、轮胎滑移或真实射弹仿真。

## 5. 首轮记录与结论

最终参数的 CPU 回放：

| 比赛时间 | 事件 |
| --- | --- |
| 1.54 s | 轮足进入 P1 |
| 约 2.54 s 后 | 满足驻留，开始持续得分（首个正增量日志在 2.56 s） |
| 11.50 s | A 命中 B，只有 A 冷却 |
| 11.60 s | B 仍能还击，A 降为 2 HP；P1 永久失效，累计 9.06 分 |
| 11.62 s | A 选择 P2 并转移 |
| 14.96 s | A 在圈外再次受击，降为 1 HP；P2 不失效 |
| 20.00 s | 高墙按固定方向倾倒，规划更新；仍有效的瞄准不被清零 |
| 20.14 s | A 生命清零，立即结束；B 剩 2 HP；P2 仍有效但未得分 |

总分 9.06，均来自 P1。本轮不是四足“获胜”演示，而是规则闭环和基线失败案例。

最小机器人中心到墙外轮廓距离约 0.421 m；双方最小中心间距约 0.850 m。仅为运动学中心约束检查，不能推导全机无接触或实机安全。

初步发现：P1 开局被掩体保护，人形抵达有效射击位置前，轮足已获得较长得分窗口；之后简单 A* 又不能妥善处理人形拦截。因此暂时不能声称“1 秒驻留已经解决直接冲点”。下一轮应分别验证出生位置/人形施压路线、驻留 1/1.5/2 s、瞄准参数和风险感知绕行策略，使用多随机种子比较，避免同时改所有因素。

调试过程保留说明：最初 60/30 s 配置在坍塌前结束，改为 40/20 s；随后扫掠检查发现人形可能进入倾倒范围，加入规划预留；避碰检查发现机器人重叠风险，加入保守停止线；最后取消场地变化时对未受影响瞄准的错误全局重置。没有指定命中时间表，也未为了演示胜利替换随机种子。
