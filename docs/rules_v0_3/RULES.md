# R0 掩体占点任务赛规则规格 v0.3

日期：2026-10-21。状态：规则设计草案；已有独立首轮原型，具体采用条款与限制见 [FIRST_TRIAL.md](FIRST_TRIAL.md)，尚未接入训练。

本版目的：将已确认的机制整理为明确的状态、事件与验收要求。它不是对现有 Demo 实现情况的描述，也不是已冻结的正式赛事规则。

标记约定：**[已确认]** 为用户明确同意的方向；**[建议]** 为本版为闭合规则提出的工程口径；**[待定]** 为尚未选定或验证的参数。建议项在确认前不得当作正式规则发布。

配套文件：`rules_draft.json` 为不可直接运行的配置草案；`ACCEPTANCE_CASES.md` 为设计验收案例，不是已经全部通过的测试报告。首轮可执行配置另存为 `configs/trial_v3.json`，不要用本草案覆盖它。

本次确认更新：人形同圈不阻止四足驻留或计分，必须有效命中才能触发受击后果；所有目标点失效时立即结束。两项已从建议/待定移入已确认规则。

## 1. 比赛定义

**[已确认]** 本赛评价四足执行占点任务的得分，人形充当攻击型施压对手。不是双方对称积分赛，也不以淘汰人形直接判四足获胜。全文“四足 A”泛指当前待评价平台；普通四足或轮足的最终机型和分组不由本规则自动确定。人形记为 B。

- 双方初始各 3 HP；一次有效命中扣目标 1 HP；双方不复活。
- 四足仅通过目标点获得积分；命中或淘汰本身没有直接加分。
- 人形不参与积分排名。其首版决策树以攻击施压为主，不训练人形策略。
- 四足 HP 归零立即结束，保留已经合法获得的积分。
- 人形 HP 归零不结束四足任务；四足继续利用尚有资格的点计分。
- 多个固定目标点在本局同时有效，不移动、不定时切换；个别点可因四足受击永久失效。
- 人形仅仅进入目标圈，不阻止四足驻留或计分；必须有效命中才能触发该点失效。
- 所有目标点失效时立即结束，保留四足已经获得的积分。
- 场地在固定时刻发生一次指定高墙的固定坍塌。

正式成绩以四足积分为主。存活时间、受击、失效点、碰撞和任务响应作诊断指标，不在首版暗中加权成总分。未来训练奖励与比赛积分分别定义、分别记录。

## 2. 地图、位置与信息

### 2.1 场景范围

**[已确认方向 / 建议解释]** 开局采用平整地面、高低墙和目标标记；去掉原有沙地与固定碎石。本版建议同时去掉原起伏路段，使开局仅有墙体障碍；该解释需在场景制作前核对。坍塌残骸是唯一计划中的中途地形变化。

**[建议]** 初版以现有 12×8 m 样场和两个位置固定的目标点为候选，不立即改动几何。实际目标点数量、位置、半径、机器人外廓与通道宽度仍需复核。各目标圈不得重叠，以保证一次圈内受击只影响一个点。出生点位于圈外。

### 2.2 R0 信息接口

**[已确认]** 四足预先知道地图，并持续获得对手位置；墙后也知道对方位置。知道位置不等于能够命中：射线和朝向仍由独立裁判检查。

**[建议]** 双方获得对称的比赛信息，首版建议接口为：

| 字段 | 含义与边界 |
| --- | --- |
| 自身状态 | 当前位姿、速度、HP、自己的冷却状态 |
| 对方状态 | 当前位姿与速度、公开 HP；对方朝向/速度属于建议公开字段，位置公开已确认 |
| 地图 | 当前有效几何、目标位置、可通行约束、地图版本号 |
| 任务状态 | 已用比赛时间、四足积分、各点是否失效 |
| 事件 | 已发生的命中、目标失效、墙体变化和终止原因 |

对方瞄准累计值和冷却剩余时间是否公开，单独列为待定；默认建议暂不提供，双方可根据公开命中事件推断。不能读取对手未来动作或规划路线。射击随机数、未来命中时刻及未发生的随机结果不作为策略观测。

R0 首版的定位噪声、时延是否为零须在实验配置中明示。本版本不评价视觉识别或自主定位，不把辅助位置输入描述为机载感知能力。

## 3. 瞄准、命中与冷却

### 3.1 有效瞄准

**[已确认]** 正前总计 60°，即水平左右各 30°。不沿用旧 Demo 的 ±10°攻击角度。

设攻击方为 i、目标为 j，固定在各自躯干坐标系的代表点为 p_i、p_j。首版建议观察点与受击点使用同一个代表点，避免无意引入两套高度造成单向遮挡。代表点必须随真实姿态变换，不能随意加高或下降来获得优势。

以下条件全部满足时，攻击方处于有效瞄准：

1. 攻击方与目标均存活，比赛正在进行。
2. 攻击方自身不在攻击冷却中。
3. p_j 相对攻击方水平前向的夹角绝对值不大于 30°。
4. p_i 到 p_j 的三维线段不穿过当前有效遮挡体。
5. 如果最终采用射程上限，双方代表点距离不超过该上限。

**[待定]** 射程是否采用旧草案的 8 m；代表点精确坐标；是否另外限制竖直视角。首版建议暂不增加竖直角阈值，但三维遮挡必须保留。

墙体与坍塌后的残骸均参与遮挡。不能继续用已经消失的高墙阻挡射线，也不能只更新视觉而遗漏碰撞/遮挡。机体前向必须来自有效姿态，禁止逻辑瞬间转身；自身几何不得误算为射线遮挡。

**[建议]** 没有额外的“扣扳机”动作：裁判在有效瞄准期间自动执行随机命中过程。四足通过路线与机体朝向决定是否持续瞄准。不沿用旧 Demo 仅在某些状态允许标记的请求窗口。

### 3.2 连续瞄准状态

每个攻击方分别维护连续瞄准时间 a_i。

- 有效瞄准连续成立：a_i 增长。
- 遮挡、超角度、超射程或目标失效：a_i 清零。
- 攻击方成功命中：a_i 清零，攻击方进入自身冷却。
- 冷却期间：a_i 始终为零；结束后重新建立瞄准。

以上重置方式为**[建议]**，用于第一版明确、可复算的实现。

**特别规定 [建议]：被命中不自动清空受击方自己的瞄准时间。** 如果受击方仍存活且自身瞄准仍有效，可以继续原有攻击过程。受击导致四足占点中断，与其攻击状态是两套独立机制。

### 3.3 条件命中率

**[已确认]** 随连续瞄准时间增长，条件命中率提高；人形增长更快。

建议模型：

`lambda_i(a) = lambda_max × (1 − exp(−a / tau_i))`

lambda 的单位为 1/s，不是单帧概率。初版建议双方共享 lambda_max，只令 `tau_B < tau_A`，把差异集中在人形进入高命中率的速度上。

定义累计条件发生率：

`H_i(a) = lambda_max × [a − tau_i × (1 − exp(−a / tau_i))]`

在未命中且持续有效的前提下，接下来长度 dt 的区间命中概率为：

`p_i(a, dt) = 1 − exp(−[H_i(a + dt) − H_i(a)])`

从本次有效瞄准开始到 a 秒，首次命中的累计概率为 `F_i(a) = 1 − exp(−H_i(a))`。禁止把 F 当成每帧独立抽签概率。

**[建议]** 射击判定使用独立裁判时钟，不使用渲染帧率；按方独立管理随机流并记录种子。可采用累计发生率超过指数随机阈值的等价实现，使连续有效瞄准下的首次命中抽样与渲染帧数无关。几何有效性采样误差仍需另外验收，不因概率公式正确就视为零误差。

双方自身冷却期间均不允许产生新命中；每次命中后的新瞄准是新的概率过程。不能把一次命中后的剩余累计进度带到下一次攻击。

### 3.4 独立冷却

**[已确认]** 任意命中后，仅成功命中的攻击方冷却，不是双方共同冷却，也不是被命中方冷却。

| 事件 | 生命变化 | 攻击状态 |
| --- | --- | --- |
| A 命中 B | B −1 HP | 仅 A 进入冷却；B 如存活可继续攻击 |
| B 命中 A | A −1 HP | 仅 B 进入冷却；A 如存活可继续攻击 |
| 同一裁判时刻双向命中 | 同时各 −1 HP | 双方都因各自成功命中而进入自己的冷却 |

冷却只限制攻击，不自动停止移动、转向或占点。人形不因处在自己的冷却中而免疫四足攻击。

**[建议]** 初版双方冷却时长相同，避免同时叠加攻击速率差异；具体秒数待定。

## 4. 目标点、驻留与积分

### 4.1 持久状态与瞬时状态分离

每个目标点保存整局有效资格 `eligible[k]`，初始均为 true。某点因四足圈内受击变为 false 后，本局不再恢复。

另保存驻留时间 `dwell[k]` 与当前是否正在计分。离开目标点会清除驻留进度，但不会自行取消整局资格。

建议状态表示：

`可得分/圈外 → 驻留累积 → 持续计分`

`驻留累积或持续计分 --圈内受击--> 本局失效`

`驻留累积或持续计分 --离圈--> 可得分/圈外`

失效不可逆，只能通过下一局完整重置恢复。命中人形或人形死亡均不能恢复已失效点。

### 4.2 进入与驻留

**[已确认]** 连续驻留达到门槛后开始持续计分；不是完成门槛时一次性获得一笔分数。

**[建议]** 使用四足躯干参考点在水平面的位置判断是否在圈内；这是任务资格判断，不能代替整机碰撞与安全外廓检查。首版允许圈内移动，不设静止或低速门槛。

**[建议]** 首版驻留门槛暂取 1 s，计分速率暂取 1 分/s。达到门槛前的时间不追溯计分。例如从零开始连续合法驻留 2.5 s，门槛为 1 s，则获得 1.5 分。

离圈、受击、失去合法占点条件后停止积分。再次进入未失效点，必须重新完成驻留；旧积分保留，不因重新进入再发放一次性奖励。

### 4.3 受击时取消哪个点

**[已确认]** 以受击事件发生时四足的位置为准：

| 四足受击时状态 | 处理 |
| --- | --- |
| 在所有目标圈外 | 扣 1 HP，不取消任何点 |
| 在有效目标圈内，尚未达到驻留门槛 | 扣 1 HP，该点整局失效 |
| 正在有效点计分 | 扣 1 HP，停止该点计分，该点整局失效 |
| 已在失效点内部 | 扣 1 HP；不额外取消其他点 |
| 刚离开某点，在圈外受击 | 不追溯取消已离开的点 |

旧积分不回扣；受击后无法通过离圈、重新进入、等待冷却或淘汰人形恢复资格。失效圈仍可通行。

**[建议]** 理想定位下，圆边界 `distance == radius` 视为圈内，命中与占点使用同一个函数。将来加入定位不确定性时再设计统一保护带，不能让边界对占点算圈内、对受击算圈外。

### 4.4 人形同圈不阻止占点

**[已确认]** 人形进入、停留或离开四足所在目标圈，本身不清零驻留、不暂停计分，也不取消目标资格。两者同圈时，四足继续按正常条件累积驻留或计分，人形自己不得分。

人形必须对四足形成有效命中，才触发扣血、占点中断及所在目标点整局失效。仅处于瞄准状态、发起未命中的攻击或进入圈内均不具有该效果。同圈不豁免遮挡、朝向、射程（若采用）、自身冷却和命中概率判定。

同圈允许是计分语义，不代表允许机器人碰撞、冲撞或身体重叠，安全约束仍独立执行。人形 HP 归零后停止攻击压力；其物理模型如何移除/停放见第 7 节。

## 5. 场地坍塌事件

### 5.1 固定事件契约

**[已确认]** 固定比赛时刻、固定墙体、固定方向/角度，一局仅发生一次；目标点不随事件移动或切换。

**[待定]** 指定墙体 ID、转轴、旋转角、最终残骸几何、事件时刻与过渡时间。

“固定角度”不足以定义可复现的场地：必须同时冻结转轴位置、旋转方向和最终障碍布局。最终几何一并用于显示、碰撞、遮挡和规划地图。

**[建议]** 首版采用两套固定有效地图，坍塌表现为一次受控场地重构；可视倒塌动画不决定随机碎块终态。新障碍先要求绕行，不开放跨越，以保持当前规则研究范围。

### 5.2 过渡与安全

本版不擅自规定自由坍塌物理过程，也不默认机器人可以被砸中。以下为建议实现约束：

- 预先验证坍塌前后存在可行任务路线，且目标圈不被残骸直接覆盖。
- 明确坍塌扫掠区与最终占据区的处理；禁止把残骸直接生成在机器人身体内部。
- 在固定逻辑事件时刻同步切换有效地图版本，策略收到地图变更事件。
- **建议重构时清空双方连续瞄准进度**，避免把旧地图下的锁定直接用于新遮挡关系。已存在的自身冷却不因此提前结束；仍在合法圈内的驻留不因纯地图事件自动清零。
- 过渡期间是否暂停比赛、是否设置预警禁入区域、区域内有机器人时如何裁定，须在场景施工前决定。本版配置保留 null，不通过随机延时或瞬移机器人偷偷解决。
- 若允许进入一个即将变为障碍的区域，必须先有明确规则，不能把由选手行为触发的失败全部当作场景故障并删去试次。

规则层只描述虚拟场地事件；不能作为实体高墙倒塌施工或安全方案。

## 6. 同时事件与计时

以下为**[建议]**的裁判契约。正式实现需要结合固定时间步/子步设计，但不允许改变这里的结果语义。

1. 所有事件使用同一比赛时钟；渲染时钟不参与判定。
2. 先结算截至当前事件之前已经合法获得的时间型积分。命中不能倒扣过去积分。
3. 处理该时刻应发生的地图事件、位置更新和冷却到期，取得统一状态快照。
4. 根据同一扣血前快照并行生成双方有效命中候选。不得先处理 A 的扣血再决定 B 本来是否有权命中。
5. 同时应用扣血、成功攻击方冷却，以及四足圈内受击引起的目标失效。
6. 检查四足死亡等终止条件；如果未结束，再确定之后的驻留/计分状态。

积分按合法时间长度计算，不能因为循环先后在命中时额外发放一个完整时间步的分数。积分区间跨过驻留门槛、冷却到期或地图事件时，应切分积分/判定区间，而不是把整段 dt 都当成新状态。

边界结果：

- 四足刚达到驻留门槛的同一时刻受击：该点失效，没有“门槛奖励”；此前尚未超过门槛的时间不计分。
- A、B 同刻都从 1 HP 降为 0：四足死亡，任务结束，保留四足既有积分，不另判四足击杀胜利。
- 人形刚被击杀，但同刻已生成对四足的有效命中：两次命中都生效；四足圈内目标仍会失效。
- 坍塌时刻清零瞄准这一建议若被采纳，则不使用跨越该时刻的旧瞄准候选。实现需切分时间段并记录事件优先级。
- **建议**比赛有效区间为 `[0, duration)`：先结算至终点时间的合法积分，到时结束；不在 duration 时刻再生成新攻击或地图事件。

## 7. 死亡、结束与结果

### 7.1 已确认终止

- `quadruped_eliminated`：四足 HP 归零，立即结束。
- `all_targets_invalid`：所有目标点失效时立即结束，即使四足仍有 HP，也结算并保留已有积分。
- 人形 HP 归零不自动终止，不直接授予四足胜利或积分。
- 无复活；HP 不允许恢复为正值。

### 7.2 建议终止与技术处置

- `time_limit`：达到局长，结算四足积分。
- `safety_stop`：碰撞、越界或独立安全触发后先停止；责任、成绩有效性和是否重赛单独标记，不能一律当作正常比赛完成。
- `referee_fault`：裁判/场景状态不一致，停止并保留完整日志；不得把裁判故障当作策略正常失败，也不得将选手责任故障伪装成裁判故障以删去失败样本。

**[建议]** 人形死亡后立即从攻击和规划障碍中退出；在首版仿真中隐藏或移至非比赛区域并关闭相应碰撞，不保留意外“尸体掩体”。其消失是显式比赛事件，不是普通运动动作。实际机器人死亡后的安全停放另行制定。

若到时未淘汰人形，四足仍按已获得积分正常结算。HP 不自动转换为积分，未失效点也不自动发放剩余分值。

## 8. 人形决策树要求（设计规格，未实现）

优先级建议：

1. 死亡或安全停止：退出正常动作。
2. 地图变化/当前路径无效：重新规划可达位置，不能沿旧路径穿过残骸。
3. 自身攻击冷却：转移、调整朝向或降低暴露；四足仍可攻击人形。
4. 已具备有效瞄准且不在冷却：优先维持，不因无意义移动频繁丢失瞄准。
5. 四足正在有效目标圈内：优先选择能建立合法攻击射线的位置。
6. 暂无有效攻击：在可达的候选攻击位置中选择，考虑路径、射线、朝向代价与自身暴露；不是无条件最短距离追逐。

人形不以获得积分为目的，也不能通过单纯站入目标圈阻止四足计分。可以为了建立合法攻击条件进入圈内，但决策树不得额外加入“人形在圈内即停止四足计分”的机制。

双方均遵守已公布的速度、角速度、制动和响应限制。不给人形瞬间朝向四足的特权。增加目标保持/切换阈值，避免每帧选择不同墙角导致振荡。

首版先做一个明确的基线对手；后续再评估守点施压、主动追击与绕侧等变体。固定对手的得分不能直接描述为通用对抗能力。

## 9. 参数状态与试验候选

以下数值仅用于提出第一组可检验假设，**没有运行新规则试验，也不意味着已平衡**。

| 参数 | 状态 | 候选值或处理 |
| --- | --- | --- |
| 初始 HP / 单次伤害 | 已确认 | 双方 3 / 1 |
| 水平瞄准角 | 已确认 | 总计 60°，左右各 30° |
| 目标点数量 | 待定 | 建议先 2 点，复用现有位置作为候选 |
| 圈半径 | 待定 | 0.9 m 候选，需与外廓/布局联检 |
| 驻留门槛 | 待定 | 1 s 候选，与攻击参数联合校准 |
| 计分速率 | 待定 | 1 分/s 候选 |
| 局长 / 坍塌时刻 | 待定 | 120 s / 60 s 候选，不沿用演示 60 s 上限 |
| 自身攻击冷却 | 待定 | 双方各 2 s 候选；彼此独立 |
| lambda_max | 待定 | 双方 1.5 /s 候选 |
| tau_A / tau_B | 待定 | 1 s / 0.5 s 候选；人形更快 |
| 射程 | 待定 | 8 m 候选；不是已确认约束 |
| 裁判更新间隔 | 待定 | 0.02 s 候选；与渲染帧率解耦 |
| 机型、速度与角速度 | 待定 | 另行制定；不直接继承演示数值 |
| 坍塌墙体与转轴/角度 | 待定 | 尚未选定，必须有最终几何与路径检查 |
| 人形同圈 | 已确认 | 不影响驻留或计分；有效命中才触发受击后果 |
| 全点失效提前结束 | 已确认 | 立即结束，保留已有积分 |

上述概率候选下，从零开始持续有效瞄准至对应时长，首次命中的累计概率为：

| 时长 | 四足 A | 人形 B |
| --- | --- | --- |
| 0.5 s | 14.8% | 24.1% |
| 1 s | 42.4% | 57.3% |
| 2 s | 81.8% | 89.6% |
| 3 s | 95.4% | 97.6% |

此表是公式计算，不是仿真或实机命中率测量；也不是每帧抽签概率。圈内受击会永久失去该点，叠加人形更快的命中增长后可能过难，必须通过简单策略对照校准。

## 10. 日志、回放与规则验收

最少记录：配置版本/哈希、地图版本、机器人身份、裁判时间、双方位姿/前向/代表点、射线遮挡结果、有效瞄准与中断原因、累计瞄准、命中概率/随机流事件、HP、自身冷却、目标圈内状态/资格/驻留、积分增量、场地事件、终止原因和故障归属。

建议事件名：`aim_started`、`aim_broken`、`hit`、`cooldown_started`、`cooldown_ended`、`target_entered`、`target_left`、`target_invalidated`、`scoring_started`、`scoring_stopped`、`collapse_applied`、`robot_eliminated`、`episode_finished`。高频状态与离散事件分开存放，事件引用同一时间戳和序号。

先实现裁判与纯规则案例，再接机器人运动；不把生成 GIF 成功当作裁判正确。验收用例见 `ACCEPTANCE_CASES.md`，目前均未执行。

随后比较：直接冲点、固定路线、持续躲藏、先消灭人形、规则型掩体机动。应检查“某个简单套路在所有条件下都占优”以及“所有策略都无法得分”，不预设冲点一定错误或学习策略一定更好。

报告积分分解：人形存活期/死亡后、坍塌前/后、每个目标点。固定随机种子用于复现；多个地图/种子用于比较。每方独立随机流避免对手额外随机调用改变自己的命中序列；不同策略仍可能产生不同事件，不能把“种子相同”误称为“命中结果必然完全相同”。

## 11. 与现有 Demo 的实现差距

当前 `scripts/tactical_logic.py` 仍是旧演示：有全局命中暂停、固定锁定门槛、定时切点、可见信息过滤与任一方归零即停止等行为。**本规格没有修改这些代码，不可声称运行 `--demo --tactical` 就能得到新规则。**

实际施工前顺序建议：确认待定条款 → 冻结一组试验配置 → 纯规则裁判和回放测试 → 地图状态切换 → 人形基线决策树 → 接入已验证运动执行 → 多策略校准 → 新演示。训练另行开展。

概率公式背景可参考 [NIST 条件发生率与累计概率关系](https://www.itl.nist.gov/div898/handbook/apr/section1/apr123.htm)。具体 lambda 曲线、参数和比赛用途为本项目设计建议，不是该来源提出的赛事规则。
