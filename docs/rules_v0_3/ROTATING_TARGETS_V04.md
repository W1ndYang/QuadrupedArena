# R0 v0.4：5 秒限时占点 + 人形加快转向

本次只改目标生命周期、人形转向/搜索速度，以及对应策略目标切换与显示。未增加训练，未更改风险绕行权重、射击命中函数或地图。

## 目标生命周期

1. 开局只激活 P1；P2 不显示、不计分。
2. **四足第一次进入当前点的圈内即触发**，不是等驻留达标后才触发。此时启动 5 秒有效期。
3. 仍需连续驻留 1 秒，然后每秒 1 分；一次刷新实例最多获得 4 分。离圈会清空驻留进度，但不暂停或重置 5 秒有效期。
4. 到期立即失效，下一点在同一裁判更新中出现。四足策略在下一次 20 ms 更新切换目标。
5. 沿用两个位置，依配置顺序 P1 → P2 → P1 → P2 循环。返回相同位置是**新刷新实例**，不是恢复旧实例。每次有独立编号、计时和驻留状态，历史累计分数保留。
6. 圈内受击仍导致当前实例提前失效，并立即刷新下一点；在未激活位置或圈外受击，只扣血、不触发点切换。
7. 新点未被四足触发时不会自动过期；当前版本不是“从刷新时刻就倒计时”，也不是随机采样新坐标。
8. 循环刷新模式不再使用“所有目标失效”作为终止条件。四足 HP 清零或到达原有 40 秒上限结束；人形被淘汰不阻止后续刷新。

边界处理：先结算截至有效期/比赛终点的合法分数，再处理到期和命中；同一步到期与命中不重复刷新。比赛终点优先于新点刷新；致死命中不再生成下一实例。所有判断以 50 Hz 裁判时间为准，不受 GIF/视频帧率控制。

## 人形速度参数

| 参数 | 旧值 | 新值 |
| --- | --- | --- |
| 身体转向上限 | 1.2 rad/s，约 69°/s | 3.0 rad/s，约 172°/s |
| 巡逻点扫视 | 0.9 rad/s，约 52°/s | 2.4 rad/s，约 138°/s |
| 最后位置搜索扫视 | 0.75 rad/s，约 43°/s | 2.4 rad/s，约 138°/s |
| 单次巡逻点扫视时长 | 1.2 s | 1.8 s |

转身 180° 的理论最短耗时从约 2.62 s 缩短至约 1.05 s。1.8 秒巡逻扫视旋转约 248°，与 120° 感知视野组合，理想无遮挡时能够覆盖一周方向。仍是有界转向，不是瞬间朝向真实目标。

保留：120° 理想几何感知、8 米距离、遮挡检测、4 秒最后观测记忆、正前总计 60° 射击判定。人形仍看不到隐藏的四足坐标；双方 3 HP、仅命中方冷却 2 秒、四足速度均不变。

## 使用

```bash
cd /home/yang/workspace/projects/quadruped-arena
bash run.sh --demo --rotating-targets --headless
# 可加 --preview 做关键帧预览。
```

配置为 `configs/trial_rotating.json`，递归继承 `trial_adaptive.json` 和 `trial_v3.json`，深度合并人形参数。旧配置与旧命令保留以便复现；新入口自动启用有限感知人形和风险绕行四足，无需另加 `--adaptive`。

界面只显示当前激活圈，并显示“待触发”或剩余秒数；底部显示刷新编号。独立美术场景 `--art` 及上一版工业场地不在这次修改范围内，本次规则 GIF 沿用轻量比赛渲染场景。

CPU 检查可通过 `scripts/adaptive_motion.py --config configs/trial_rotating.json --output <新输出目录>` 运行，不需要 GPU。
