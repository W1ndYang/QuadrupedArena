## 2. 人形：只能根据可见目标与记忆行动

人形仍知道固定地图，但策略接口不接收当前隐藏的四足位置、四足路线或目标占点状态。外部观测适配器用真值计算理想可见性，策略只能拿到其返回的“观测坐标”或“未发现”。这不是用真实相机图像做视觉识别。

| 项目 | 本轮设置 |
| --- | --- |
| 发现目标的水平视野 | 总计 120°，左右各 60° |
| 感知距离 | 水平 8 m |
| 遮挡 | 人形与四足代表点之间的三维墙体线段检查 |
| 感知频率 | 每个 0.02 s 裁判步一次 |
| 丢失目标记忆 | 最后看到的位置，最多保留 4 s，不更新隐藏位置 |
| 搜索方式 | 追查最后观测位置；到达后扫视；记忆到期回到巡逻 |
| 无目标巡逻 | 地图中固定航点，不根据隐藏四足坐标选择航点 |
| 巡逻扫视 | 航点处约 1.2 s，约 0.9 rad/s；不是全向感知 |
| 实际射击 | 先发现目标，仍须满足原来的正前总计 60°、无遮挡、射程、自身冷却等裁判条件 |

决策顺序：

```text
淘汰 → 停止
有当前可见观测 → 面向观测位置，瞄准或保持自身冷却
没有当前观测、记忆未过期 → 搜索最后观测位置
没有可用记忆 → 固定航点巡逻 + 扫视
```

人形只有在确实看到四足时才持续盯住它。受击本身不自动透露攻击方坐标；本版未添加声音、来弹方向或受击方位传感器。人形冷却期间仍可观察；若目标消失，也可搜索移动，冷却只禁止攻击。

一个仿真步的顺序为感知/决策 → 限速运动 → 裁判结算，画面中的观测和最终位姿可能相差一个 0.02 s 步长；裁判始终再次检查运动后的真实遮挡和朝向。

## 3. 四足：风险路线、主动避险、冷却窗口

R0 四足继续获得人形当前位置。本轮还沿用公开机体朝向作火力方向估计；不使用对方连续瞄准累计值或随机命中阈值来决策。冷却窗口只从已经发生的人形命中事件和公开的 2 秒冷却规则推算，不预测未来命中时刻。

### 路线不再只比较距离

使用加权网格搜索：

```text
路径代价 ≈ 路程 + 风险权重 × 沿路暴露代价
```

- 墙体实际遮挡或超射程：暴露代价为零。
- 人形正前射击范围内：高代价。
- 人形视野内、暂未转入射击范围：中等代价，提前预警。
- 暂在人形背后但无遮挡：仍有较小代价，不能假定人形永不转身。
- 靠近人形：增加代价，并把周围 1 m 区域作为动态避让区。
- 剩余 1 HP：风险权重乘 1.8；已知人形冷却窗口内，风险权重降低但不归零。
- 路径简化时也核对暴露代价，避免把绕行路线重新拉直成穿过火力区的捷径。

目标仍以最近的有效点为主，不是完整的任务级最优规划。在目标圈内优先选相对靠内的到达位置，避免刚碰到边界就停在掩体保护不足的位置。若圆心被动态安全区挡住，可考虑圈内其他候选位置；整圈不可达则等待重规划，不穿过人形。

### 行为状态

| 状态 | 行为 |
| --- | --- |
| 风险绕行 | 朝目标前进，结合当前位置、墙体和人形火力方向重规划 |
| 驻留 | 在目标内累计得分；安全时扫视，不再隔墙持续转向人形 |
| 主动避险 | 威胁持续约 0.24 s 或受击后，优先找能切断视线的附近位置 |
| 冷却窗口转移 | 从公开命中事件推算窗口，降低路线风险权重，尝试转移 |
| 等待重规划 | 当前没有可行路径时等待，不用瞬移穿过机器人或墙体 |

常规重规划间隔 1 s，受击、目标失效、地图变化或切换到避险等事件可提前触发。避险至少保持约 0.6 s，减少状态来回切换。

执行层增加轮足低速倒退：只在避险时允许，倒退上限 0.8 m/s。原前进上限 1.1 m/s、加速度上限 2 m/s² 和转向上限 2.5 rad/s 不变。它仍是差速轮运动学映射，并未验证真实轮足的平衡、摩擦或倒退能力。

本次最终回放实际从 25.96 s 开始出现倒退，累计倒退采样时间约 1.04 s，最大倒退速度达到 0.8 m/s；不是仅增加了一个未使用的配置开关。

外部安全层检查墙体中心间距和双方 1.05 m 中心间距；安全层可限制移动，但不把对手隐藏位置提供给人形的转向/搜索决策。保护性停止不等于完整身体碰撞求解。

## 5. 对照结果：不要把人形变弱误当作四足变聪明

比较两组都使用同一个有限感知人形，固定地图、赛规、时间上限和配对随机种子。对照组轮足保留最近点/普通 A* / 停下看对手的基线；新组同时更改风险规划、避险、驻留朝向、目标圈内到达位置和倒退执行，因此不是只改变一个风险权重的单变量实验。

高风险暴露使用策略的启发式风险值 ≥0.8 统计，包含朝向、遮挡、距离与近距离惩罚；不等同于实际命中概率或扣除冷却后的有效射击时长。可见性时长、剩余 HP、实际命中数另外记录。两组回合长度也不同，原始文件提供暴露时间占比。

种子 20261021 用于调试，另外四个是冻结当前策略后补测；仍然只是同一地图上的少量样本，不能证明统计显著性或泛化能力。相同种子对应相同初始独立随机流，但策略改变了瞄准片段数量，后续抽签消费时序不同，不代表每次攻击使用了相同随机样本。

结论：本版改善了“无视威胁”这一行为，也有初步的生存收益；但第二点转移太保守。下一步适合增加剩余时间预算、累计任务进度与风险的权衡，而不是继续无限提高避险权重。此次没有把比赛成绩偷偷改成“生存优先”；正式评价仍然是占点得分。
