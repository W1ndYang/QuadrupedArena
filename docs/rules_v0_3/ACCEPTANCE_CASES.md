# 规则 v0.3 验收案例清单

日期：2026-10-21。**下列均为测试设计，尚未实现或执行。** 旧 Demo 的 11 项已通过测试不能作为本清单通过的证据。

依据：`RULES.md`。包含建议条款的案例，须先确认条款，再固定预期结果。

测试层次：先做无机器人运动的裁判单元测试，再做日志回放，然后做场景与控制集成；本轮没有启动任何一层新测试。

## A. 瞄准与条件命中率

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| A01 | 无遮挡，目标水平偏角 29° | 满足角度条件；自身冷却等其他条件仍需分别检查 |
| A02 | 无遮挡，目标水平偏角 31° | 无效瞄准，不能产生新命中 |
| A03 | 理想姿态下恰好 30° | 按不大于 30°的建议口径有效；数值容差不得被做成额外宽角 |
| A04 | 目标在前方，但高墙切断代表点连线 | 无法命中，即使 R0 始终知道其位置 |
| A05 | 低墙后不同代表点高度 | 按真实三维线段分别判定，不能固定宣称低墙后安全 |
| A06 | 连续瞄准中短暂被墙遮挡 | 按建议口径清零，再出现时从零开始 |
| A07 | 目标暂时超角度后返回 | 按建议口径清零，不能保留旧瞄准进度 |
| A08 | 四足受到非致命命中，自身瞄准仍有效 | 不进入受击者冷却；按建议口径保留自身瞄准状态 |
| A09 | 相同有效几何轨迹，仅改变渲染 FPS | 裁判过程不变；不得因画面帧数改变命中统计 |
| A10 | 连续无遮挡、固定朝向，改变裁判 dt | 首次命中分布符合解析 F(a)；明确离散事件定位误差，不能宣称几何采样完全无误差 |
| A11 | 相同瞄准时长及共享上限，tau_B < tau_A | 人形条件命中率更高，累计首次命中率也更高 |
| A12 | 记录种子和所有裁判输入后重放 | 复现命中、冷却与积分事件；记录不同策略下事件抽样不可直接一一等同 |
| A13 | 目标在自身冷却中、攻击方不在冷却 | 目标不获得免疫；攻击方仍可命中 |
| A14 | 无有效瞄准、冷却期间或目标已死亡 | 新命中数恒为零，不能沿用之前已抽中的缓存结果 |

概率统计测试需预先固定样本量、置信判据与误差容限，不以“单次碰巧命中/未命中”判定公式正确。条件命中率曲线与几何有效性测试分开。

## B. 冷却与并行事件

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| B01 | A 命中 B，B 尚存活 | B 扣血，只有 A 新增自身冷却 |
| B02 | B 命中 A，A 尚存活 | A 扣血，只有 B 新增自身冷却；A 所在目标另按占点规则处理 |
| B03 | A 在自身冷却中持续对准 B | A 无新命中，瞄准累计保持零 |
| B04 | A 的冷却到期 | 可重新开始瞄准，不携带旧命中进度或立即兑现旧攻击 |
| B05 | 同一裁判时刻 A/B 均命中 | 同时扣血；各自因攻击成功进入冷却，不受遍历顺序影响 |
| B06 | A/B 均剩 1 HP，同刻互相命中 | 双方归零；以四足死亡结束，保留原积分，不判四足击杀胜利 |
| B07 | B 剩 1 HP，A 将其击杀，同时 B 已形成有效命中 | 两次命中都结算；若 A 在有效圈内，该点仍失效 |

## C. 目标资格、驻留与积分

示例采用候选驻留 1 s、计分速率 1 分/s；这些参数并未冻结。

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| C01 | 从零连续合法驻留 0.9 s | 0 分，目标仍有效 |
| C02 | 从零连续合法驻留 2.5 s | 1.5 分，不追溯计算最初 1 s |
| C03 | 驻留 0.6 s 后离圈，再驻留 0.6 s | 无积分；不能跨离圈累积到 1.2 s |
| C04 | 已获得 2 分后离圈，再正常进入 | 原 2 分保留，重新完成驻留后继续按时间计分 |
| C05 | 在有效圈内驻留不足门槛时受击 | 扣 1 HP，该点整局失效，即使尚未获得分数 |
| C06 | 在有效圈内正在计分时受击 | 保留此前分数，从命中时起不再获得该点积分，资格永久失效 |
| C07 | 从失效圈离开又返回 | 不恢复资格，也不因重新进入发放奖励 |
| C08 | 圈外受击 | 只扣血，不使任何点失效 |
| C09 | 在 P1 失效圈受击，P2 仍有效 | 只扣血，不能连带取消 P2 |
| C10 | 圈外命中人形 | 四足没有直接积分；任何目标资格均不变化 |
| C11 | 四足在有效圈中命中人形，自己进入冷却 | 冷却本身不停止占点；尚未达到驻留门槛则继续合法累积 |
| C12 | 四足在圈内移动，但始终未出圈 | 按无静止要求的建议口径允许累积驻留/计分 |
| C13 | 四足恰在圆边界受击 | 与进入判定共享边界口径；不能一边计分一边声称在圈外 |
| C14 | 同刻首次达到驻留门槛并受击 | 该点失效，不产生门槛奖励，不多发一个时间步积分 |
| C15 | 人形进入四足所在目标圈，但未有效命中 | 四足正常累积驻留或计分；资格不变，人形自己不得分 |
| C16 | 人形退出同圈或死亡，四足未受击且持续满足占点条件 | 四足驻留和计分不中断，不需重新驻留；人形自己始终不得分 |
| C17 | 配置中目标圈重叠 | 场景验收失败，不能临时按数组顺序决定本次取消哪个点 |
| C18 | 人形死亡后，四足进入之前失效的点 | 仍不计分，死亡不恢复目标资格 |
| C19 | 双方同圈，人形持续瞄准但尚未命中 | 四足继续合法驻留或计分，不能把被瞄准当作受击 |
| C20 | 双方同圈，人形有效命中四足 | 四足扣血，所在有效点立即整局失效；不是仅暂时争夺暂停 |

## D. 生命与结束

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| D01 | 四足 HP 降为 0，积分为 7.4 | 立即结束，最终 7.4 分，不追加存活/淘汰奖励 |
| D02 | 人形 HP 降为 0，四足仍有有效目标 | 比赛不因人形死亡结束；四足可继续占点 |
| D03 | 只有一个点失效，另有有效点 | 不因单点失败结束，四足可以转移 |
| D04 | 所有点失效但四足仍有 HP | 立即以 all_targets_invalid 结束并保留已有积分，不能记为四足死亡；结束后不再发生比赛动作或得分 |
| D05 | 达到局长但四足仍存活 | 按 time_limit 结算；无额外击杀、HP 或未完成目标奖励 |
| D06 | 命中候选落在 duration 时刻 | 按建议有效区间 [0,duration) 不再产生新攻击；此前合法积分结算至 duration |
| D07 | 下一局重置 | HP、资格、驻留、积分、冷却、瞄准、地图及对手状态全部重置；种子按配置重新初始化 |

## E. 坍塌与场景一致性

| ID | 场景 | 预期结果 |
| --- | --- | --- |
| E01 | 同一场景配置重复运行 | 坍塌时刻、墙体、转轴/角度和最终残骸一致 |
| E02 | 原高墙倒下后射线通畅 | 不再被旧高墙碰撞/遮挡体阻断 |
| E03 | 最终残骸挡住连线或通道 | 同时反映在渲染、遮挡、碰撞与规划地图中 |
| E04 | 坍塌在原瞄准过程中发生 | 若采用瞄准清零建议，重新建立瞄准，不兑现跨地图的旧命中候选 |
| E05 | 坍塌时攻击方尚在自身冷却 | 不借地图变化清除或缩短冷却 |
| E06 | 四足在目标圈合法驻留，地图变化不影响该圈 | 不仅因地图版本变化而清零驻留；仍须存活、保持圈内且目标有效，人形同圈不构成中断条件 |
| E07 | 残骸与机器人或任务圈产生禁止交叠 | 施工前必须有已定义的处理；不默认瞬移、不随机延后、不悄悄判死 |
| E08 | 新几何让任务全部不可达 | 场景设计不通过；不能将无解地图归因于策略能力不足 |
| E09 | 界面帧率改变或渲染暂停 | 事件由裁判时钟触发，不能按画面播放进度改变比赛时刻 |

## F. 人形基线与行为合理性

| ID | 检查 | 评价方式 |
| --- | --- | --- |
| F01 | 人形是否只是无条件追逐 | 检查其是否能选择具备合法射线的可达位置，而非卡在墙边 |
| F02 | 人形是否频繁放弃有效瞄准 | 记录瞄准中断原因与路径目标切换，检查是否是树结构抖动 |
| F03 | 四足直接冲点 | 测量得分、失效点与 HP；不能预设其必须失败，但不能在所有场景都无代价占优 |
| F04 | 四足永远躲藏 | 无合法占点不应获得积分，辅助训练奖励不得伪装成正式成绩 |
| F05 | 四足先消灭人形 | 分解人形死亡前后积分，检查是否完全主导任务而架空掩体与坍塌 |
| F06 | 固定路线对比根据场地变化重新规划 | 比较坍塌后到点、合法积分与碰撞，确认场地事件有实际决策意义 |
| F07 | 多种子 / 多对手变体 | 报告分布与失败，不只挑成功 GIF；正式测试组合预先固定 |

## 验收记录模板

每个案例记录：规则/配置版本、输入状态或轨迹、事件时刻、预期输出、实际输出、随机种子/流信息、通过或失败、偏差解释。尚未确认的分支标记 BLOCKED_BY_RULE_DECISION，不默认选择对当前程序最方便的结果。
