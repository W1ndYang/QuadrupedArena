## 实测结果与范围

20 次决策推进 40 秒比赛：12 分，四足剩 1 HP，人形 34.90 秒淘汰。相同配置/种子的旧风险绕行基线 8 分、21.86 秒四足淘汰。基线在本轮全部决策提交完成后运行，没有用其未来轨迹指导本次规划。

这是单种子、全知状态、已知对手策略的可行性演示，不是模型优越性的统计结论。LLM 观测字段更丰富，接口/控制频率与旧策略不同。随机序列随有效瞄准过程消耗，共用种子并不等于命中时刻可以逐项配对。

决策等待总计 1490.63 秒，平均 74.53 秒，中位数 67.04 秒；口径是观测就绪至动作接受，包含工具调用/交互/上下文处理。不是纯推理计时。当前会话没有提供逐次 token usage，因此记录 null，不估算。

本轮是 CPU 裁判与运动学状态闭环，再由 Isaac 原生重放；不包含接触动力学、步态训练、相机视觉闭环或端侧推理测试。强模型负责选择动作，底层执行器只有固定的路径与姿态控制。

验证：105 项自动测试通过；本轮结束后，仅重放已承诺的 20 条相同指令，逐项精确复现全部 2001 条状态快照。此检查不是新策略试验，不选择替代动作，也不覆盖原比赛数据。检查摘要见运行目录的 `verification.json`。

## 数据流

```text
当前地图/状态/对手信息 → 冻结比赛时间 → 外部模型
       ↑                                  ↓ 技能 JSON
新观测和执行结果 ← 运行 100 × 0.02 秒 ← 校验/存档/固定技能
```

接口文件 `scripts/llm_trial.py`：

- `init`：仅在全新目录初始化比赛，保存原规则配置、源码快照和协议，输出观测。
- `observe`：读取当前状态，不推进时间，也不重置决策计时起点。
- `probe`：只检查当前几何路径、长度和视线；不预测未来人形移动和命中。
- `act`：校验当前观测编号和动作，独占创建执行前承诺记录，再推进两秒（终局可提前结束），输出新观测。

固定技能：`MOVE / HOLD / AIM / SCAN / STOP`。本次实际用了前三类。`MOVE` 可以给出 goal、via、speed_limit、reverse；路线由几何 A* 产生，没有把旧风险策略藏在技能里面。攻击仍由原裁判进行持续几何与条件命中判定。

`facing` 不表示独立炮塔：MOVE 仍受路径跟随器的机身方向约束，通常到达后才使用指定朝向；reverse 开启后可倒退。`AIM` 是固定的逐帧转向跟踪技能，不是模型每帧重新决策。

可选 `target_generation` 将技能绑定当前目标代次，刷新后取消过期指令。不绑定时可以提前向下一点转移。取消或几何安全检查仅让技能停止，不会替模型选择新策略。

模型可见真值位置、朝向、血量、目标计时、已累计瞄准、冷却和人形当前策略/记忆/路径，以及确定性规则。输出不包含命中随机阈值、RNG 状态或未来实际轨迹。`.private_state.pkl` 是受信任本地检查点，不能当作外部上传格式，不要反序列化来源不明的文件。

## 文件与计时

| 文件 | 内容 |
| --- | --- |
| `protocol.json` | 观测权限、种子、两秒周期、计时范围与 token 不可用说明 |
| `observations/NNN.json/png` | 当前结构化状态与程序绘制顶视图（非相机图像） |
| `requests/NNN.json` | 模型当步提交的动作、依据、选择摘要、取舍和预期 |
| `decisions/NNN.json` | 执行前固化的动作、路径与决策端到端等待时间 |
| `decisions/NNN_outcome.json` | 该次实际执行结果、纯 CPU 推进耗时 |
| `timeline.json / events.json` | 50 Hz 真实状态记录与裁判事件；LLM 事件导出过滤随机阈值 |
| `decision_timing.csv` | 各步等待/执行时间，token 留空并标为 unavailable |
| `audit_sha256.json` | 承诺、请求、观测和比赛记录的内容摘要 |
| `source_snapshot/` | 初始化时源码与配置；不因后续渲染改动覆盖 |
| `baseline/` | LLM 结束后运行的旧策略参考结果 |

每步说明是基于可核验信息的决策摘要，不是内部推理逐字记录。第 N 步观测图的青色路径表示上一指令尚未走完的部分，新指令路径见本步承诺文件中的 compiled_route。

## 本轮暴露的问题

1. 第一次跨区移动仍被命中，后段 32 秒开始的转移又在 34 秒被迫回撤，说明风险时机选择并不完美。
2. 人形受击后没有基于声音/受击方向的搜索响应；这个策略弱点显著影响了 25 秒附近的攻防，必须披露。
3. 两秒窗口内不做战术打断，对快速威胁变化可能反应迟缓。
4. 最后 4 秒消耗在转身与绕障上，淘汰对手后没有及时获得额外占点分数。

下一阶段应先统一观测与技能接口，再做多种子对照及事件打断消融；真实端侧部署与小模型能力是后续独立验证任务，不由本轮结果外推。
